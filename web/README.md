# Nudge Agent website

Landing page for Nudge Agent, built with Next.js.

## Run it

```bash
cd web
npm install
npm run dev
```

Then open http://localhost:3000.

## Layout

| Path | What it is |
|---|---|
| `app/page.tsx` | The page and its copy |
| `app/globals.css` | All styles and design tokens |
| `components/HeroTrip.tsx` | The animated trip in the hero |
| `components/StateTabs.tsx` | Anchored, Excursion, Drifting tabs |
| `components/ProfileTabs.tsx` | Goal sentence to task profile example |
